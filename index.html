Rules

⚔️ Crystal Ville SMP – Server Rules ⚔️

Welcome to Crystal Ville! Hum sab barabar hain, yahan koi king ya staff nahi hai. Game ke andar poori chhoot hai (Griefing, PVP, Looting sab allowed hai), par dosti bani rahe aur game smoothly chale, isliye ye kuch rules hain jo sabko follow karne hain:

  • 👑 Hum sab barabar hain, yahan koi king ya staff nahi hai, isliye sabko ek dusre ke saath respectful rehna hoga.
  • ⚔️ Game ke andar poori chhoot hai (Griefing, PVP, Looting sab allowed hai), par game ka gussa game tak hi rakhna, Discord par aakar toxic mat hona.
  • ❌ X-ray, Fly, ya kisi bhi tarah ke hacked clients aur cheats ka use bilkul mana hai, pakde jaane par seedha ban kiya jayega.
  • 🏗️ Server par koi bhi aisi lag machine ya redstone contraption mat banana jisse server crash ho ya ping kharab ho.
  • 🚫 Ek dusre ki personal life par koi comment nahi karega, real-life threats ya dushmani bilkul bardaasht nahi hogi.
  • 🤫 In-game ladaai ya loot ke baad Discord par rona-dhona ya faltu ka drama create mat karna, apna badla game ke andar hi lo.
  • 🤝 Jo bhi player in rules ko todega, use baaki sabhi doston ki aapsi sehmati se server se bahar kar diya jayega.
